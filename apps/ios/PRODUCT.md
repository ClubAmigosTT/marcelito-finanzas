# Marcelito iOS

## Register

product

## Platform

ios

## Users

Aplicación financiera privada para una sola persona, sincronizada conceptualmente con Marcelito web. Se usa para consulta cotidiana, revisión de decisiones y carga mensual de estados de cuenta desde Archivos.

## Product Purpose

Mostrar una lectura clara del patrimonio, explicar los flujos entre cuentas y permitir revisar o corregir interpretaciones automáticas. El primer acceso usa credenciales; los siguientes pueden desbloquearse con Face ID.

## Positioning

Marcelito convierte movimientos dispersos en una historia financiera editable y útil para decidir.

## Brand Personality

Precisa, serena y humana.

## Anti-references

No imitar una web dentro del teléfono, no reemplazar controles del sistema y no depender exclusivamente del color.

## Design Principles

1. Seguir las convenciones de iOS.
2. Explicar el origen de cada recomendación.
3. Mantener editables las categorías y relaciones.
4. No guardar datos de baja confianza sin revisión.

## Accessibility & Inclusion

La interfaz usa Dynamic Type, etiquetas de accesibilidad, colores semánticos y respeta Reduce Motion.
